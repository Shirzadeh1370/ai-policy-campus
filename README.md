# AI Assistant Policy Campus

An educational prototype helping students understand course AI policies and ask instructors for clarification.

## Features

- Course and professor information saved locally in the browser.
- Syllabus and assignment policy workflow with green, yellow, and red guidance.
- Clarification email drafts for instructors.
- Accessibility controls and multilingual interface options.
- Guided demonstration and optional AI study aids and speech.

## Run locally

Requires Node.js 20 or later.

```bash
npm start
```

Open http://127.0.0.1:4173. Optional cloud features require a local `.env` configured from `.env.example`; never commit API keys. See `README.txt` and `FINAL_DEMO_README.txt` for detailed notes and limitations.

## Status

Imported from the September 25, 2026 V6 demo package. This is an educational prototype; its guidance does not replace course policies or instructor approval. Translation and accessibility features have not been independently certified.
